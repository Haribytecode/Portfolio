Blackpeak — 32-bit x86 OS Kernel

A monolithic, higher-half x86 kernel built from absolute zero in C and Assembly. Every subsystem designed, implemented, and debugged by hand — GRUB to Ring 3.

  • GRUB Multiboot, custom assembly bootstrap, and tailored linker scripts
  • Dual-layered VM: bitmap physical frame allocator + recursive page directory + INT 14 demand paging
  • User/kernel isolation via hardware CR3 switching — fully sandboxed user environments
  • Preemptive round-robin scheduler with low-level ASM context switching and per-task kernel stacks
  • INT 0x80 syscall gateway with TSS-based stack switching for Ring 0 ↔ Ring 3 transitions
  • VGA text console, UART serial debug logging, GDB remote kernel targets
  • Verified 100% runtime parity across QEMU and VirtualBox
  • Currently: designing abstract VFS interface for storage drivers and initrd ramdisk
